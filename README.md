# 🎉 家庭抽奖软件

一个简单易用的网页版抽奖软件，适合家庭成员间的公平决策。非常适合决定"今天谁做家务"这类问题。

## ✨ 功能特点

- 👥 **参与者管理**：轻松添加和删除家庭成员
- 🎁 **多奖项支持**：支持多个奖项，每个奖项可设置多个名额
- 🎰 **随机抽取**：公平的随机抽奖算法
- 📝 **历史记录**：自动保存最近100条抽奖记录
- 💾 **本地存储**：数据保存在浏览器本地，无需服务器
- 📱 **响应式设计**：支持桌面和手机访问
- ⚡ **即开即用**：无需安装，直接打开HTML文件使用

## 🚀 使用方法

### 快速开始

1. **下载文件**：将 `index.html`、`style.css` 和 `script.js` 三个文件下载到同一个文件夹

2. **打开应用**：双击 `index.html` 文件即可在浏览器中打开

### 使用步骤

#### 第一步：添加参与者
- 在左上方"添加参与者"区域输入参与者名字（例如：妈妈、爸爸、小明等）
- 点击"➕ 添加"按钮或按回车键
- 重复上述步骤添加所有家庭成员

#### 第二步：添加奖项/任务
- 在右上方"添加奖项/任务"区域输入要分配的任务（例如：洗碗、拖地、整理房间等）
- 设置需要该任务的人数（默认为1人）
- 点击"➕ 添加"按钮
- 可以添加多个不同的任务

#### 第三步：开始抽奖
- 点击下方"🎰 开始抽奖"按钮
- 系统会随机为每个任务分配参与者
- 结果会立即显示在屏幕上

#### 第四步：查看历史
- 所有抽奖记录会自动保存
- 可以在"📝 抽奖历史"区域查看之前的抽奖结果

## 💾 数据存储

- 所有数据自动保存在浏览器的本地存储中
- 关闭浏览器后，数据不会丢失
- 每台设备/浏览器有独立的数据
- 可以点击"🔄 重置"按钮清空所有数据

## 🎨 界面说明

- **左上面板**：添加和管理参与者
- **右上面板**：添加和管理奖项/任务
- **中间面板**：抽奖操作和结果显示
- **下方面板**：查看抽奖历史记录
